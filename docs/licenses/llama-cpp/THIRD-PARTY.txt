Third-party code compiled into llama.cpp as Codiclens builds it

Scripts/build-llama.sh builds llama.cpp release b11567 (commit 972b5fc) with
Scripts/llama.cpp-no-logits.patch applied and links libllama, libmtmd, the ggml
libraries and vendor/hash statically into Codiclens. Besides llama.cpp's own
MIT License (LICENSE, next to this file), that build carries the code below.
Each notice is copied from the file named, in llama.cpp's source tree at b11567.
